# 天眼通 2.0 运行手册 — 报告计划

- 报告类型：技术交付文档（运行步骤 + 代码结构说明）
- 受众：开发团队 / 项目验收方 / 新接手成员
- 语言：中文
- 结构：Intro → §1 概览（含架构分层）→ §2 环境准备 → §3 五步运行指南 → §4 代码结构 → §5 API 清单 → §6 数据库设计 → §7 核心代码讲解 → §8 演示账号与权限 → §9 常见问题与降级 → 来源
- Color preset: Custom:indigo-purple — cue: 用户指定第一版前端 indigo-purple 渐变风格（#6366f1 → #8b5cf6）
- Intro mode: contained — cue: 技术文档，无 Hero 媒体素材（no-image fallback）
- 图表：无 ECharts 量化图表；架构用 HTML/CPS 分层块；目录树用 pre 代码块；无图片
- 组件：metric 卡（概览指标）、分组表格（环境/端口/API/数据表）、步骤卡（运行步骤）、代码块（命令与核心代码）、callout（注意事项）、tag（HTTP 方法）
- 宽表格策略：API 清单为附录级宽表，允许全宽 + 换行单元格；权限矩阵全宽
- 引用：本地文件以代码字体标注（如 backend/tyt/main.py）；外部链接放 footer Sources
